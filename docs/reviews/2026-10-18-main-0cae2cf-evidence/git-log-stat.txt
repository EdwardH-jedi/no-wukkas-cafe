    game paused, or the browser stopped audio) was started on that context,

    frame the context is running again. started() still drops a generation
    that a newer line or stopVoice moved past, so a cancelled line never
    starts.

    and "browser-suspended". Regression test in tests/audio/manager.test.ts
    for the cancel half (a line stopped while queued never starts).
