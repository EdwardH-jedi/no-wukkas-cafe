### ResizeObserver and phone layout

`src/ui/rushHud.ts:106`은 observer를 보관하지 않고 disconnect도 하지 않는다. 그러나 현재
`src/app/boot.ts:208`에서 HUD를 한 번 만들고 show/restart는 같은 root를 재사용한다.

현재 앱에서 확인되지 않은 leak을 결함으로 주장하지 않는다. 향후 HUD 재생성이 추가되면
observer 해제가 필요하다.

새 `offsetHeight` 읽기와 CSS property 쓰기는 ResizeObserver callback 안에만 있으며 per-frame
`update`에 추가되지 않았다. `--rtl-h`는 관측 대상 #rtl 자신이 아니라 형제 #pos의 위치/높이에
사용되어 직접적인 resize feedback loop도 없다. 실제 layout 횟수/비용은 browser 차단으로 미측정이다.

구현자 phoneHud는 첫 customer, 빈 ticket rail, Medium register만 검사한다. 누적 tickets,
Large text register, ring button의 scroll 접근성, 회전/viewport 변화는 빠져 있다.
`max-height: max(180px, ...)`의 최소 높이 때문에 공간이 작은 상태의 clipping 여부는 실제 browser에서
추가 측정해야 한다. CSS만으로 제품 FAIL을 확정하거나 JS 계산을 browser 실측으로 대체하지 않았다.
